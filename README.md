# Site da Jhully Kerolin — Nutricionista

Site institucional desenvolvido para apresentar o trabalho da nutricionista Jhully Kerolin, seus serviços, formas de atendimento, especialidades, avaliações de pacientes e canais de contato.

## Principais características

- Layout responsivo para computador, tablet e celular;
- Cabeçalho adaptativo, com redução ao rolar a página;
- Menu mobile com navegação em formato hambúrguer;
- Seção principal com apresentação profissional e chamada para agendamento;
- Seção "Sobre" com foto e informações da nutricionista;
- Área de especialidades e modalidades de atendimento;
- Seção interativa explicando como funciona a consulta;
- Apresentação dos acompanhamentos disponíveis;
- Galeria do consultório;
- Avaliações de pacientes;
- FAQ;
- Botão flutuante de WhatsApp;
- Links para Instagram, LinkedIn e e-mail;
- Página de Política de Privacidade;
- Favicon adaptado para tema claro e escuro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
